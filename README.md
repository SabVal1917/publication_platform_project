### Тема проекта:

## **Платформа для публикации и обсуждения статей по программированию**

**Страницы на Сайте (Frontend):**

- Главная страница со списком статей
- Cтраница отдельной статьи с комментариями
- Cтраницы для создания/редактирования статей
- Страница профиля пользователя
- Страницы регистрации и входа

---

**API и Взаимодействие Пользователя с Сайтом:**

API предоставляет возможности:

- Регистрации, вход, просмотр/редактирование профиля
- Для статей функционал: получение списка, просмотр,
  создание, редактирование, удаление, лайки
- Для комментариев функционал: добавление, редактирование, удаление, лайки.
- Пользователь взаимодействует с сайтом через формы и кнопки, которые отправляют соответствующие запросы к API.

---

**Что Будем Хранить в БД:**

- **Пользователи** (ник, почта, пароль),
- **Статьи** (заголовок, содержимое, автор, дата, количество лайков/комментариев),
- **Комментарии** (содержимое, автор, к какой статье/комментарию относится),
